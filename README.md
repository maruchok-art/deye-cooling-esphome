# 🌡️ Deye Inverter Cooling Controller

Автоматичне керування вентиляторами охолодження інвертора Deye 6кВт 
через ESP32 + ESPHome + Home Assistant.

## Можливості

- Плавне регулювання обертів за температурою інвертора
- Гістерезис для уникнення осциляцій
- EMA фільтр для згладжування температурних стрибків
- Аварійний режим 100% при критичній температурі
- Failsafe при втраті зв'язку з Home Assistant
- Веб-інтерфейс на ESP32 для налаштування без HA
- Моніторинг реальних RPM через тахометр
- Всі параметри налаштовуються з UI без перепрошивки

## Крива охолодження

25% ──── 45°C ──── плавно ──── 60°C ──── 80%
↓
65°C → 100% (аварія)

## Залізо

| Компонент | Модель |
|-----------|--------|
| Мікроконтролер | ESP32 DevKit v1 38-pin CP2102
| Вентилятори | AVC DS09225R12H 92мм 4-pin PWM
| Блок живлення | AC/DC 3-12V 2A
| Перетворювач | LM2596 з вольтметром 12V→5V
| Перемички | Набір мама/тато

## Схема підключення

БЖ 12V (+) ────────────────── Жовтий дріт вентиляторів

└── LM2596 IN+ → OUT+ 5V → ESP32 VIN

БЖ 12V (-) ────────────────── Чорний дріт вентиляторів

└── LM2596 IN- → OUT- → ESP32 GND

ESP32 GPIO16 ───────────────── Синій дріт (PWM сигнал)

ESP32 GPIO17 ───────────────── Зелений дріт одного вентилятора (тахометр)

ESP32 GND ──────────────────── Чорний дріт вентиляторів (спільна земля)
*Примітка щодо підключення:* Якщо ви використовуєте кілька вентиляторів, підключайте до `GPIO17` (тахометр) зелений дріт **тільки від одного вентилятора**. Дроти тахометра інших вентиляторів потрібно заізолювати і нікуди не підключати, інакше покази RPM будуть некоректними. Зовнішній підтягуючий резистор не потрібен, в коді активовано `INPUT_PULLUP`.

## Налаштування ESPHome

1. Встанови [ESPHome](https://esphome.io)
2. Скопіюй `deye-cooling.yaml`
3. Заміни WiFi SSID та пароль
4. Проший ESP32
5. Додай пристрій в Home Assistant

## Вимоги (Prerequisites)

Для роботи цієї автоматики ваш інвертор Deye вже має бути підключений до Home Assistant (наприклад, через інтеграцію Solarman або Solar Assistant). 

**Важливо:** У файлі `deye-cooling.yaml` в блоці `sensor` змініть `entity_id` на той, який відповідає сенсору температури DC у вашому HA:
  - platform: homeassistant
    entity_id: sensor.deye_dc_temperature # <-- Змініть на свій сенсор!
    id: deye_dc_temp

## Параметри керування

| Параметр | За замовчуванням | Опис |
|----------|-----------------|------|
| Start Temp | 45°C | Початок збільшення обертів |
| Max Temp | 60°C | Температура максимальних робочих обертів |
| Emer Temp | 65°C | Аварійний режим 100% |
| Hysteresis | 2°C | Зона гістерезису |
| Idle Speed | 25% | Мінімальні оберти |
| Max Speed | 80% | Максимальні робочі оберти |
| Failsafe Speed | 40% | Оберти при втраті зв'язку |
